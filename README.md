## Qué es

Anclora Synergi es un producto premium del ecosistema con un patrón editorial propio, orientado a la coordinación de sinergias y colaboraciones entre entidades y productos de Anclora.

## Categoría en el ecosistema

## Funcionalidades principales

- Coordinación de colaboraciones entre entidades del ecosistema
- Acceso controlado con base de datos serverless (Neon)
- Interfaz con soporte de tema claro/oscuro

## Stack tecnológico

| Área | Tecnología |
|---|---|
| Framework | Next.js, React |
| Base de datos | Neon (PostgreSQL serverless) |
| UI | Lucide React |
